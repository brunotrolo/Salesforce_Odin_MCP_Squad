# Salesforce Odin MCP Squad

Um único servidor MCP para o time inteiro (POs, devs, QA, arquitetos) usar as skills Salesforce no Claude Code, com identidade, perfis de acesso, atualização automática, runtime local assinado e base de conhecimento (RAG).

> **Status:** plano. Nada foi desenvolvido ainda.

- 📐 [Plano de arquitetura completo](docs/PLANO.md)

**Em uma frase:** a pessoa instala um CLI, faz login uma vez e passa a pedir em linguagem natural. O Odin identifica quem é, escolhe a skill que ela pode usar, entrega a versão aprovada mais recente direto do GitHub, garante que o runtime e os hooks de segurança da máquina estão atualizados, e responde com conhecimento citado.

Skills cobertas: Discovery-to-Backlog, Journey Designer, Journey Developer, Data Architect e Test Automator.
